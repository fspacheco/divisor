# Divisores de tensão e corrente

Página interativa de apoio à disciplina de **Eletricidade** para praticar operações com
circuitos **série** e **paralelo**.

Usa só um arquivos simples com HTML, CSS e JavaScript puros: sem bibliotecas, sem build, sem servidor. Funciona offline, no computador
e no celular.

## Conteúdo de referência

Baseado no material de aula do Curso Técnico em Eletrônica — IFSC, Campus Florianópolis, elaborado por Fernando S. Pacheco.
